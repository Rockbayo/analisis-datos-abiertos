# Proyecto de Minería de Datos - Semana 7

## Reglas de Integración y Flujo de Trabajo

Para mantener el orden en el repositorio, todos los integrantes deben seguir estrictamente este flujo para aportar su código:

1. **Actualizar localmente:** Antes de empezar, asegúrate de tener la última versión ejecutando `git checkout main` y luego `git pull`.
2. **Crear o usar tu rama asignada:**
   - Integrante 1: `feature/dimension-poblacional`
   - Integrante 2: `feature/dimension-territorial`
   - Integrante 3: `feature/dimension-temporal`
   - Integrante 4: `feature/dimension-multivariada`
3. **Desarrollar:** Realiza tus cambios en tu rama. Debes hacer como mínimo tres (3) commits descriptivos relacionados con tu dimensión.
4. **Subir cambios:** Sube tu rama al repositorio remoto (`git push`).
5. **Pull Request (PR):** Ve a GitHub y crea un Pull Request hacia la rama `main`.
6. **Revisión:** Solicita la revisión del Integrante 1 (Administrador). Aplica las correcciones si son solicitadas.
7. **Fusión:** Solo el Integrante 1 puede aprobar y fusionar (merge) el Pull Request hacia `main`. ¡No trabajes directamente sobre main!
